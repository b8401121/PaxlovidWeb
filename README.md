# PaxlovidWeb 雲端藥歷交互作用比對系統

PaxlovidWeb 是一個專為基層診所設計的「Paxlovid (口服抗病毒藥) 用藥交互作用警示篩選系統」。本系統採用純前端靜態網頁架構，無需伺服器後端或任何複雜的構建工具（Build Tools），旨在提供極致的輕量化與部署便利性。

## 🌟 主要功能

- **📋 雲端藥歷一鍵解析**：支援直接貼上健保雲端藥歷文字，系統會自動透過正則表達式萃取藥品代碼、就醫日期、來源院所等關鍵資訊。
- **🚦 交互作用自動分級**：內建四大分級（⛔ 禁忌停藥 8 天、⚠️ 潛在交互需減量、✅ 安全無禁忌），自動將貼上的藥歷進行分類。
- **🖨️ 衛教單張列印與預覽**：提供 A4 格式的專業衛教單張生成。在列印前可於「預覽視窗」中自由點擊編輯內容（如病人姓名、病歷號等）。
- **📑 複製文字報告**：一鍵產生純文字報告，方便醫護人員快速貼入 EMR 電子病歷系統或 LINE 中。
- **🎨 臨床主題切換**：內建「☀️ 臨床明亮」、「🍵 護眼溫和」、「🌙 臨床深色」三種佈景主題，減輕長時間看診的視覺疲勞。
- **🔐 簡易前端防護**：進入系統前需輸入基礎帳號密碼，利用 `sessionStorage` 進行驗證，關閉分頁即登出。

## 🛠️ 技術架構與開發規範

本專案**強烈堅持採用 Vanilla HTML/CSS/JS**。
- **❌ 絕對禁用**：Node.js、Vite、React、Vue、Webpack、TypeScript 編譯等任何需要 Build 步驟的工具。
- **✅ 核心檔案**：
  - `index.html`: 主應用程式結構與登入遮罩。
  - `styles.css`: 系統樣式與列印 (`@media print`) 排版。
  - `main.js`: 負責 DOM 操作、事件綁定、列印預覽與 UI 狀態切換。
  - `parser.js`: 核心的文字解析引擎，負責將雲端藥歷字串轉換為結構化資料，並執行自動去重與日期排序。
  - `data.js`: 存放交互作用藥物資料庫（`proh`, `dont`, `pote`, `safe`, `safe2`, `DICT`）。

## 🚀 部署方式

本專案直接部署於 GitHub Pages：
1. 修改完程式碼後，執行 Git Commit。
2. 執行 `git push origin main`。
3. GitHub Pages 將自動抓取 `main` 分支的內容並更新網站。
4. 使用者在瀏覽器端按下 `Ctrl+F5` 強制重新整理即可載入最新版本。
